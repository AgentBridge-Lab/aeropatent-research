1Executive Summary

원격탐사·탑재체 분야의 ‘합성개구레이더’ 기술축에 연결된 대표 문헌은 전체 표본 기준 8건입니다. 원격탐사·탑재체 검색축에서 118,575개 고유 패밀리가 집계되었습니다. CPC 후보 수이며 검증된 항공우주 특허 수가 아닙니다. 기술별 구성요소와 적용 환경을 원문에서 확인한 뒤 비교 범위를 좁혀야 합니다.
