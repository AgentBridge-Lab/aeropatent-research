1Executive Summary

위성체·열·전력 분야의 ‘열제어 루버’ 기술축에 연결된 대표 문헌은 전체 표본 기준 1건입니다. 위성체·열·전력 검색축에서 29,722개 고유 패밀리가 집계되었습니다. CPC 후보 수이며 검증된 항공우주 특허 수가 아닙니다. 기술별 구성요소와 적용 환경을 원문에서 확인한 뒤 비교 범위를 좁혀야 합니다.

  • ‘열제어 루버 (thermal louver)’ 기술축을 위성체·열·전력 분야 안의 독립 검색축으로 정의합니다.
  • 구동기·바이메탈, 방사율 가변 구조, 개폐 제어와 고장 시 안전상태를 검토합니다.
  • 세부기술 검색어와 상위 분야 CPC·출원인 집계를 교차 확인하되, 세부기술 단위 수치가 없는 경우 상위 분야 값을 대신 사용하지 않습니다.
  • 대표 문헌이 연결된 경우에만 문헌 수·연도·관할·주요 특허를 대표 문헌 표본 집계값으로 표시합니다.

13근거와 해석 한계
  • 표시된 문헌 수와 분포는 대표 문헌 표본 기준이며 세부기술 전체 모집단을 뜻하지 않습니다.
  • 상위 분야 수치(위성체·열·전력)는 기술 환경을 이해하기 위한 배경이며 열제어 루버의 직접 집계값이 아닙니다.
  • 전략 검토나 권리 판단 전에는 검색식 보강, 패밀리 중복 제거, 원문 청구항 검증이 필요합니다.
