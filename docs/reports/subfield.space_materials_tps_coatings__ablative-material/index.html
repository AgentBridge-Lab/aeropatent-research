1Executive Summary

우주재료·TPS·코팅 분야의 ‘삭마재’ 기술축에 연결된 대표 문헌은 전체 표본 기준 2건입니다. 우주재료·TPS·코팅 검색축에서 225,901개 고유 패밀리가 집계되었습니다. CPC 후보 수이며 검증된 항공우주 특허 수가 아닙니다. 기술별 구성요소와 적용 환경을 원문에서 확인한 뒤 비교 범위를 좁혀야 합니다.

2분석 범위와 데이터 기준
보고서 유형세부분야분석 기준대표 문헌 표본 2건 · 전체 표본 기간
  • ‘삭마재 (ablative material)’ 기술축을 우주재료·TPS·코팅 분야 안의 독립 검색축으로 정의합니다.
  • 삭마재의 조성·밀도·열분해 거동과 열유속 조건별 질량 손실, 잔탄층 안정성을 비교합니다.
  • 세부기술 검색어와 상위 분야 CPC·출원인 집계를 교차 확인하되, 세부기술 단위 수치가 없는 경우 상위 분야 값을 대신 사용하지 않습니다.
  • 대표 문헌이 연결된 경우에만 문헌 수·연도·관할·주요 특허를 대표 문헌 표본 집계값으로 표시합니다.
