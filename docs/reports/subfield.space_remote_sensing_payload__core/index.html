‘원격탐사 핵심’ 기술축은 원격탐사·탑재체 분야의 독립 검색축입니다. 현재 세부기술 단위 대표 문헌이 없어 상위 분야 집계와 검색 기준을 분리해 제시합니다. 원격탐사·탑재체 검색축에서 118,575개 고유 패밀리가 집계되었습니다. CPC 후보 수이며 검증된 항공우주 특허 수가 아닙니다. 기술별 구성요소와 적용 환경을 원문에서 확인한 뒤 비교 범위를 좁혀야 합니다.
